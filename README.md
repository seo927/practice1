# 영어 단어장

브라우저에서 바로 여는 영어 단어 학습 페이지입니다. 카드로 뜻을 확인하고, 퀴즈로 맞춘 뒤, 단어장에서 다시 찾아볼 수 있습니다.

## 실행

`index.html`을 더블클릭하면 됩니다. 설치나 서버는 필요 없습니다.

## 학습 방법

- **카드**: 단어를 누르면 뜻과 예문이 나옵니다. `알아요`는 외운 단어로, `다시 볼게요`는 아직 낯선 단어로 남깁니다.
- **퀴즈**: 뜻을 보고 단어를 고르거나, 단어를 보고 뜻을 고릅니다. 맞히면 외운 단어로 기록됩니다.
- **단어장**: 영어 단어나 한글 뜻으로 검색하고, 주제(기초, 일상, 감정, 학업, 여행)로 걸러 볼 수 있습니다. 항목을 누르면 예문이 열립니다.

단어는 48개입니다. **발음 듣기**를 누르면 영어 발음을 들을 수 있습니다.

## 단축키

카드 화면에서 사용할 수 있습니다.

| 키 | 동작 |
| --- | --- |
| Space | 카드 뒤집기 |
| → | 알아요 |
| ← | 다시 볼게요 |
| Enter | 퀴즈에서 다음 문제 |

## 학습 기록

외운 단어, 오늘 학습한 수, 퀴즈 정답률은 이 브라우저에 저장됩니다. 다른 브라우저나 다른 컴퓨터에서는 기록이 보이지 않습니다. 단어장의 **기록 지우기**로 초기화할 수 있습니다.
